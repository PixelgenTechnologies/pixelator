pixelator.pna.pixeldataset.io.QueryBuilder
==========================================

.. py:class:: pixelator.pna.pixeldataset.io.QueryBuilder

   Build `Query` objects for pixeldataset read operations.


   .. py:method:: adata_X_query(db_name: str, components: list[str] | None = None, column_renames: Mapping[str, str] | None = None) -> Query

      Build AnnData X query for a single underlying sample DB.

      Note: marker filtering is intentionally not pushed down into SQL (column
      selection); consumers can filter markers in-memory after materialization.

      :param db_name: The attached database of the sample.
      :param components: Components to keep, or None for all.
      :param column_renames: ``stored column -> new column``. Every stored column
                             must exist in the table.
