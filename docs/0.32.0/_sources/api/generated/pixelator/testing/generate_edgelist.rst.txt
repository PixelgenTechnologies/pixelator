pixelator.testing.generate_edgelist
===================================

.. py:function:: pixelator.testing.generate_edgelist(n_cells: int, n_nodes: int, n_edges: int, min_neighbors: int, panel: pixelator.pna.config.panel.PNAAntibodyPanel, n_crossing_edges: int = 1, hashing_fraction: float = 0.2, rng=None, *, hashing_indices: collections.abc.Sequence[int] | None = None, n_cell_types: int = 1, cell_type_effect: float = 1.0, n_shared_markers: int = 0) -> polars.DataFrame

   Generate a populated edge list for ``n_cells`` cells with crossing edges.

   Each cell is an independent graph (see :func:`~pixelator.testing.topology.generate_cell_graph`) populated
   with umis and markers (see :func:`populate_cell`). The per-cell edge lists are
   concatenated and tagged with a unique ``component`` id, and
   ``n_crossing_edges`` chimeric edges are added: for each, two random edges are
   sampled and a new edge joins the umi1/marker_1 of the first with the
   umi2/marker_2 of the second. Crossing edges have a null ``component``.

   Each cell also gets a cell type, cycled within each hashing index so that
   every hashing index carries every cell type (see ``_cell_types_per_cell``).

   :param n_cells: number of cell graphs to generate.
   :param n_nodes: number of nodes per cell graph.
   :param n_edges: target number of edges per cell graph.
   :param min_neighbors: minimum number of candidate neighbors per node, before filtering.
   :param panel: antibody panel providing the available markers.
   :param n_crossing_edges: number of chimeric edges to add across cells.
   :param hashing_fraction: fraction of each cell's umis assigned to hashing markers.
   :param rng: a seed or numpy Generator for the random number generator.
   :param hashing_indices: hashing indices to assign to cells. ``None`` uses every
                           index in the panel.
   :param n_cell_types: number of cell types; each boosts its own block of
                        high-abundance markers (see ``_marker_probabilities``).
   :param cell_type_effect: factor applied to the probabilities of a cell type's
                            marker block. ``1.0`` plants no cell-type signal.
   :param n_shared_markers: number of high-abundance markers that receive the
                            ``cell_type_effect`` boost in every cell, whatever its cell type.

   :returns: A polars DataFrame with columns ``umi1``, ``marker_1``, ``umi2``,
             ``marker_2``, ``component`` (null for crossing edges) and a random
             positive ``read_count`` per edge.
