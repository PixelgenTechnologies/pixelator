pixelator.testing.pixelfile.write_pna_pxl
=========================================

.. py:function:: pixelator.testing.pixelfile.write_pna_pxl(edgelist: polars.DataFrame, panel: pixelator.pna.config.panel.PNAAntibodyPanel, path: str | pathlib.Path, sample_name: str = 'synthetic') -> pathlib.Path

   Write a populated edge list to a single-cell-pna pxl file.

   The edge list must have the columns produced by
   :func:`~pixelator.testing.molecules.generate_edgelist`:
   ``umi1``, ``marker_1``, ``umi2``, ``marker_2``, ``component`` and
   ``read_count``. Crossing edges (rows with a null ``component``) are dropped
   before the AnnData is built, so only genuine per-cell components are
   aggregated. The edge list is selected down to the pxl schema, written to the
   file, and an AnnData is built and stored alongside it.

   :param edgelist: populated edge list from
                    :func:`~pixelator.testing.molecules.generate_edgelist`.
   :param panel: antibody panel providing the marker metadata.
   :param path: output path for the ``.pxl`` file.
   :param sample_name: sample name recorded in the pxl metadata.

   :returns: The path to the written pxl file.
