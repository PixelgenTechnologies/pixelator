pixelator.pna.graph.component_recovery.build_pxl_file_with_components
=====================================================================

.. py:function:: pixelator.pna.graph.component_recovery.build_pxl_file_with_components(parquet_file: pathlib.Path, panel: pixelator.pna.config.PNAAntibodyPanel, sample_name: str, path_output_pxl_file: pathlib.Path, multiplet_recovery: bool, edge_cycle_verification: bool, min_read_count: int, refinement_options: pixelator.pna.graph.community_detection.StagedRefinementOptions, component_size_threshold: bool | tuple[int, int], n_cores: int = 1) -> tuple[pixelator.pna.pixeldataset.PNAPixelDataset, pixelator.pna.graph.report.GraphStatistics]

   Build a new PXL file with components recovered from edgelist.

   Starting from an edgelist parquet file, (collapse step output) this function recovers components
   using community detection with staged refinement, and writes a new PXL file containing the
   edgelist with resolved components. Components are resolved based on the provided community
   detection options.
   It also computes and returns statistics about the graph.

   :param parquet_file: Path to the input parquet file containing the edgelist. (collapse step output)
   :param panel: Name of the panel used in the experiment.
   :param sample_name: Name of the sample.
   :param path_output_pxl_file: Path to the output PXL file.
   :param multiplet_recovery: Whether to perform multiplet recovery.
   :param edge_cycle_verification: Whether to perform edge cycle verification.
   :param min_read_count: Minimum read count threshold for an edge to be retained.
   :param refinement_options: Options for staged refinement during community detection.
   :param component_size_threshold: Min/Max size threshold for components to be retained. Can be a
                                    boolean for dynamic sizing or a tuple of two integers (Min, Max).
   :param n_cores: Number of CPU cores to use for parallel processing.

   :returns: Tuple of PNAPixelDataset and GraphStatistics
