   .. py:method:: add_panel(panel: pixelator.pna.config.panel.PNAAntibodyPanel) -> None

      Register a panel and its lookup keys in the config.

      The panel is indexed by panel name (or filename fallback), optional product,
      and aliases.

      :param panel: Panel object to add.

      :raises PanelException: If an alias already maps to a different panel key.

   .. py:method:: get_panel(panel_name: str, version: Optional[str] = None, allow_aliases: bool = True) -> Optional[pixelator.pna.config.panel.PNAAntibodyPanel]

      Resolve a panel by name/product/alias and optional version constraint.

      :param panel_name: Panel name, product name, or alias. May include an inline version specifier
                         (for example "product==1.2.0").
      :param version: Optional version specifier supplied separately.
      :param allow_aliases: If True, also resolve through configured aliases.

      :returns: The resolved panel, or None if no matching panel is found.

      :raises ValueError: If version is specified both inline and in ``version``, or if multiple
          ambiguous major/minor versions match.



   .. py:method:: list_panel_names(include_aliases: bool = False, include_archived: bool = False) -> List[str]
