pixelator.pna.amplicon.filters.TooManyN
=======================================

.. py:class:: pixelator.pna.amplicon.filters.TooManyN(count: float, assay: pixelator.pna.config.PNAAssay)

   Bases: :py:obj:`cutadapt.predicates.Predicate`


   Select reads that have too many 'N' bases.

   Both a raw count or a proportion (relative to the sequence length) can be used.


   .. py:attribute:: assay


   .. py:attribute:: cutoff


   .. py:method:: descriptive_identifier() -> str

      Return a string identifier for this predicate.

      Used in reports and added as a comment to the sequence id when writing failed reads.



   .. py:attribute:: is_proportion


   .. py:method:: test(read, info: cutadapt.info.ModificationInfo)

      Return True if the read has too many N bases.

      :param read: The read to test.
      :param info: The modification info.

      :returns: True if the read has too many N bases, False otherwise.
