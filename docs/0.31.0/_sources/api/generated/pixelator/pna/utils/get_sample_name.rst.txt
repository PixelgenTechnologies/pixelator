pixelator.pna.utils.get_sample_name
===================================

.. py:function:: pixelator.pna.utils.get_sample_name(filename: pixelator.common.types.PathType) -> str

   Extract the sample name from a sample's filename.

   The sample name is expected to be from the start of the filename until
   the first dot.

   :param filename: path to the file

   :returns: the sample name (str)
