pixelator.pna.report.models.base.SampleReport
=============================================

.. py:class:: pixelator.pna.report.models.base.SampleReport(/, **data: Any)

   Bases: :py:obj:`pydantic.BaseModel`


   Base class for all pixelator reports of `single-cell` subcommands.

   :ivar sample_id: The sample id for which the report is generated.
   :ivar product_id: The product id for which the report is generated.
   :ivar report_type: The command for which the report is generated.
   :ivar status: ``passed`` or ``failed``. JSON omits this field when the step passed.
   :ivar null_reason: Why a failed step produced a null file. JSON includes this
                      string only when ``status`` is ``failed``.
