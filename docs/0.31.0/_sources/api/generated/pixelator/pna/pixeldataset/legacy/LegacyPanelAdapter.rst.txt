pixelator.pna.pixeldataset.legacy.LegacyPanelAdapter
====================================================

.. py:class:: pixelator.pna.pixeldataset.legacy.LegacyPanelAdapter(connection: duckdb.DuckDBPyConnection, file_name: str | None = None)

   Read the panel of a pxl file that has no ``panels`` or ``panel_sources`` table.

   Files written by pixelator 0.22 through 0.30 stored ``uns['panel_metadata']``
   and the panel columns on ``var``. The panel is rebuilt from those.

   Older files only record the panel name. They do not store the panel itself,
   so they yield None and have to be regenerated by rerunning the pipeline.


   .. py:method:: read() -> pixelator.pna.config.panel.PNAAntibodyPanel | None

      Return the panel this file stores in an older layout, or None.
