pixelator.common.plot.colors.pixelgen_sequential_colormap
=========================================================

.. py:function:: pixelator.common.plot.colors.pixelgen_sequential_colormap(hue: str = 'purples', direction: int = 1, min_level: int = 1, max_level: int = _N_ACCENT_LEVELS, n: int = 256) -> matplotlib.colors.LinearSegmentedColormap

   Get a Pixelgen branded sequential matplotlib colormap for a given hue.

   :param hue: The accent color hue to build the colormap from. See
               `pixelgen_accent_colors`.
   :param direction: ``1`` for light-to-dark, ``-1`` for dark-to-light.
   :param min_level: The lightest accent color level (1-12) to include. Raise
                     this above 1 to avoid the near-white end of a hue, e.g. for
                     points plotted on a white background that would otherwise be
                     hard to see.
   :param max_level: The darkest accent color level (1-12) to include.
   :param n: The number of discrete color levels to sample the colormap at.

   :returns: A `matplotlib.colors.LinearSegmentedColormap` usable as a ``cmap=``
             argument.

   :raises ValueError: If ``hue`` is unknown, ``direction`` is not 1 or -1, or
       ``min_level``/``max_level`` are out of range or in the wrong order.
